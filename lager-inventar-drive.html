Google Drive einrichten
Einmalige Einrichtung – danach synchronisieren alle Geräte automatisch.
📋 Schritt-für-Schritt Anleitung
1
Google Cloud Console öffnen
Öffne im Browser: console.cloud.google.com
Mit deinem Google-Konto anmelden.
2
Neues Projekt erstellen
Oben links auf „Projekt auswählen" klicken → „Neues Projekt" → Name z. B. Lager App → „Erstellen"
3
Google Drive API aktivieren
Linkes Menü → „APIs und Dienste" → „Bibliothek" → Suche nach Google Drive API → Klicken → „Aktivieren"
4
OAuth-Zustimmungsbildschirm
„APIs und Dienste" → „OAuth-Zustimmungsbildschirm" → Nutzertyp: Extern → „Erstellen" → App-Name eingeben (z. B. Lager App) → deine E-Mail als Support-Kontakt → „Speichern und fortfahren" → bei Bereichen nichts ändern → „Speichern und fortfahren" → bei Testnutzer deine E-Mail hinzufügen → „Speichern"
5
OAuth Client-ID erstellen
„APIs und Dienste" → „Anmeldedaten" → „Anmeldedaten erstellen" → „OAuth-Client-ID" → Anwendungstyp: Webanwendung → Name beliebig → Bei „Autorisierte JavaScript-Quellen" klicke „URI hinzufügen" und gib ein: null (für lokale HTML-Datei) → „Erstellen"
6
Client-ID hier einfügen
Es erscheint ein Fenster mit deiner Client-ID. Diese endet auf .apps.googleusercontent.com – kopieren und unten einfügen.
Die App speichert deine Daten ausschließlich in deinem eigenen Google Drive. Kein externer Server hat Zugriff.
