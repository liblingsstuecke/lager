Google Drive einrichten
Einmalige Einrichtung – danach synchronisieren alle Geräte automatisch.
Schritt-für-Schritt Anleitung
1
Google Cloud Console öffnen
Öffne: console.cloud.google.com – mit deinem Google-Konto anmelden.
2
Neues Projekt erstellen
Oben links „Projekt auswählen" → „Neues Projekt" → Name z. B. Lager App → „Erstellen"
3
Google Drive API aktivieren
„APIs und Dienste" → „Bibliothek" → Google Drive API suchen → „Aktivieren"
4
OAuth-Zustimmungsbildschirm
„APIs und Dienste" → „OAuth-Zustimmungsbildschirm" → Extern → App-Name eingeben → E-Mail → Testnutzer: deine E-Mail → „Speichern"
5
OAuth Client-ID erstellen
„Anmeldedaten" → „Anmeldedaten erstellen" → „OAuth-Client-ID" → Typ: Webanwendung → Bei „Autorisierte JavaScript-Quellen" deine GitHub Pages URL eintragen (z. B. https://DEINNAME.github.io) → „Erstellen"
6
Client-ID hier einfügen
Die Client-ID endet auf .apps.googleusercontent.com – kopieren und unten einfügen.
Daten werden ausschließlich in deinem eigenen Google Drive gespeichert.
